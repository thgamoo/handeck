## 그림은 어디 있나

`project.json` 에는 **그림이 안 들어간다** (에셋 id 만 가리킨다 — ARCHITECTURE §1).
그림까지 든 것은 같은 폴더의 **`samaksil.handeck` 묶음**이고 **215MB 라 git 에 올리지 않는다.**
그림이 필요하면 그 파일을 앱에서 «열기» 로 열고, 구조만 보려면 `project.json` 이면 된다.

## 룰북

`rulebook.md` 가 원고다. 앱에서 **「룰북」 탭 → 「원고 가져오기」** 에 이 파일을 넣으면
지금 프로젝트에 든 것과 같은 20쪽이 만들어진다 (A5 · 접어서 중철 · A4 가로 5장).

프로젝트 파일 쪽을 다시 만들려면:

```bash
npx esbuild example/make-rulebook.ts --bundle --platform=node --format=cjs \
  --outfile=example/make-rulebook.cjs --log-level=error && node example/make-rulebook.cjs
```

앱의 가져오기와 **같은 코드**(`core/rulebook.ts`)를 쓴다. 원고를 고치고 다시 돌리면
룰북만 갈아끼워진다.

> ⚠️ **원고가 곧 정본은 아니다.** 규칙의 정본은 `sub3/docs/rules/` 이고,
> `rulebook.md` 는 그걸 인쇄용으로 추린 것이다. 규칙이 바뀌면 그쪽을 먼저 고친다.
> 구성품 개수 중 **«미정» 이라고 적힌 것**(두근!·빌런 토큰 수량, 재앙 토큰 수량)은
> 아직 확정되지 않았다.

## 검사

`npm run check` 가 이 폴더를 검사한다: 앞뒤 규격 일치, 값이 가리키는 레이어 존재,
**문서가 정한 장수와 실제 장수 일치**(능력 100 · 단서 27 · 운명 48 …), 재앙 뒷면이
운명 뒷면과 동일한지, 인쇄 묶음의 규격이 같은지. 룰북은 **쪽이 4의 배수인지**(중철),
**종이에 들어가는지**, **본문이 넘치는 쪽이 없는지**까지 본다.

## 알아둘 것

- **운명 카드가 세 덱이다.** 초·중·후반 각 16장으로 나뉘어 있고 합이 48이라 24막에 맞는다.
  **뒷면은 셋 다 같아야 한다** — 구간이 구분되면 다음에 뭐가 나올지 읽힌다.
  같은 이유로 **재앙 뒷면도 운명과 동일**하다 (tokens.md §4). 검사가 이걸 지킨다.
- **토큰 3종은 «지름만 한 네모» 다.** 두근!·빌런·조우 전부 25×25.
  펀치가 없어 가위로 자를 수 있게 네모로 뒀고, 나중에 규격만 «토큰 · 원형 25» 로 바꾸면
  크기 그대로 둥글어진다.
- **프린트묶기가 둘이다.** 63×88 카드 16덱, 25×25 토큰 3덱. 묶인 덱 아무거나
  «인쇄 / PDF» 를 누르면 묶음 전체가 한 종이에 이어 깔린다.
  > ⚠️ 묶으면 한 장에 여러 덱이 섞여 나온다. 자른 뒤 분류하는 수고가 생기므로
  > 시제품 단계에서는 이득이고 최종본은 덱별로 뽑는 편이 편하다.
- **`build.mjs` 는 옛 생성기다.** 지금 `project.json` 은 이걸로 만들지 않는다 —
  **돌리면 손으로 그린 작업본을 덮어쓴다.** 규칙 문서의 표를 코드로 옮기는 방식이
  필요해지면 참고용으로 남겨둔 것이다.
- **정본은 `sub3/docs/rules/tokens.md`.**

## 교체하면서 손본 것

작업본을 그대로 넣었더니 검사가 몇 가지를 잡았다. **덱을 복제하면서 딸려온 값들**이다.

- `expect`(기대 장수)가 실제와 어긋난 덱 **10개** — 운명 초·중·후(48→16), 재앙(3→10),
  남주성향(3→20), 캐릭터 3종, 시나리오(60→3), 플레이어 힌트(60→1). 실제 장수로 맞췄다.
- **없는 덱을 가리키던 인쇄 묶음 항목 3개** — 지운 덱의 id 가 묶음에 남아 있었다.
- **죽은 값 9개** — 조우 토큰의 이미지 레이어에서 «카드마다 다르게» 를 끈 뒤에도
  카드별 값이 남아 있었다.

> 이건 **앱 안의 파일에는 그대로 남아 있다.** `samaksil.handeck` 을 열어 쓰고 있다면
> 위 열 덱의 «기대 장수» 를 고쳐두는 편이 좋다 — 안 그러면 인쇄할 때마다 경고가 뜬다.
